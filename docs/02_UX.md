# 02 — UX / Information Architecture

## Main navigation

Recommended sections:

- Home
- Library
- Projects
- Processing Queue
- Search
- Settings

## Home

Home combines a useful dashboard with fast access to recording. Recording remains prominent but is not the only purpose of the screen.

## Recording UI

Default:

- tray + hotkey + main app;
- no always-on floating window;
- compact recording/live-transcript window is optional.

While recording, a small tray indicator and in-app state are sufficient.

## Live transcript

Default presentation is visible when the app is open. A compact window can be enabled separately. It may show:

- speaker if available;
- timestamp;
- current text;
- auto-scroll;
- current utterance highlight.

Live text is explicitly non-authoritative; the final transcript may differ.

## Processing Queue

A dedicated page shows:

- current stage;
- concise status by default;
- expandable detail;
- retry/cancel;
- locality (local/Windows);
- model/engine identity.

## Recording detail

Default layout is a split view containing:

- audio player;
- transcript;
- summary.

The summary/transcript arrangement can be changed. Audio playback follows the transcript position.

## Settings

Group settings into:

- Recording
- Transcription
- AI / Summary
- Storage
- Models
- Notifications
- Maintenance
- About

Maintenance actions:

- Clear Cache
- Reset Config
- Factory Reset (keeps Library)
- Uninstall Kakitome

Do not expose a separate Full Reset.

## Theme / accessibility

Support system/light/dark override. Keyboard navigation, screen reader semantics, focus visibility, scaling, and high-contrast behavior are first-class requirements.
