# Kakitome 2.0.1

## 変更点

- **バッテリーで使っているときに、文字起こしが進まない問題を直しました。**
  - これまでは「自動」モードだと、電源につなぐまで重い処理（文字起こし・要約）を一切始めませんでした。
  - 今後は、バッテリー残量が 30% 以上あれば、PC に負担をかけないよう控えめに処理を続けます。30% 未満のときと、Windows の省電力モードがオンのときは、電源につなぐまで待ちます。
  - 待っているときは、ホーム画面にその理由を表示します。
- **アプリが途中で終了した後、文字起こしが始まらないままになる問題を直しました。**
  - 処理の登録中にアプリが終了すると、文字起こし以降が登録されずに残っていました。今後は、次に起動したときに自動で登録し直します。
- **YouTube などの URL 取り込みで「HTTP Error 403」が出たとき、自動でやり直すようにしました。**
  - 一時的なエラーで、少し待つと成功することが多いためです。
- **「診断情報を保存」に、Windows が記録した Kakitome の異常終了・応答なしの記録を含めるようにしました。**
  - アプリ自身では記録できない種類の終了の原因を調べられます。

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.1_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.1_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.1_x64.msi`） |

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。ライブラリ・設定・モデルはそのまま残ります。

## 既知の制限

- ARM 版は、動作を確認できていません。
- NPU（AI 専用プロセッサー）には、まだ対応していません。
- 話者の区別（誰が話したか）には対応していません。
- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されることがあります。
