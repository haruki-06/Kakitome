# Kakitome / カキトメ 2.0.0

録音を「書き留める」Windows アプリ、Kakitome の最初の公開版です。ノート PC で会議・講義・動画を録音し、**この PC の中だけで**文字起こし・要約・検索まで行います。クラウドやアカウント、有料サービスは使いません。MIT ライセンスのオープンソースです。

## 変更点

- **名前を Kakitome / カキトメ に変え、オープンソースとして公開しました。**
  - 以前の非公開版（SmartRec）とは別のアプリとしてインストールされます。データの引き継ぎはありません。
- **初回起動時の自動ダウンロード**
  - この PC に合った音声認識モデルと、URL 取り込み用の yt-dlp を自動でダウンロードします。メモリ 16 GB 以上の PC では、要約用 AI もダウンロードします。
  - 従量制の接続では行いません。［設定］で止めることもできます。
  - ダウンロード中に録音したものは、準備ができた時点で自動で文字起こしします。
- **読みやすくなった録音画面**
  - 文字起こしと要約を、時刻のないふつうの文章として表示します（句点と改行を補います）。
  - クリックした位置から再生し、再生中の部分をハイライトします。再生バーの下に「現在位置 / 全体の長さ」を表示します。
- **要約が録音の種類に合わせた形になりました。**
  - 会議・講義・会話や動画を見分け、決定事項や ToDo は会議のときだけ出します。
- **設定を整理しました。**
  - 項目をタブに分け、モデルは用途ごとのカードに説明付きで並べました。
- **GPU の使い方を見直しました。**
  - 2 GB 以上の外付け GPU だけを使い、内蔵 GPU では CPU で処理します。GPU で失敗したときは CPU でやり直します。
- **新しいバージョンのお知らせ**
  - 1 日 1 回、GitHub に最新のバージョンを問い合わせ、新しい版があればお知らせします。［設定］→［全般］でオフにできます。
- **ログと「不具合の報告」**
  - ［設定］→［データとバックアップ］→［不具合の報告］で、Issue に添付する診断情報（ログ・PC の情報など）を保存できます。
  - 録音・文字起こし・要約は含みません。
- **そのほかの修正**
  - アップデートすると設定が消える問題を直しました。
  - 削除した録音を開いたときや、アップデートでアプリが閉じられるときに、アプリが落ちる問題を直しました。
  - エラーの説明を日本語で表示するようにしました。

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.0_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.0_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.0_x64.msi`） |

## インストール・アップデート

- `.msi` をダブルクリックします。
  - 「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
  - 管理者権限は不要です。
- 起動すると、必要なモデルを自動でダウンロードします。進み具合は［キュー］で確認できます。
- アップデートは、Kakitome を終了してから新しい `.msi` を実行します。ライブラリ・設定・モデルはそのまま残ります。
- アンインストールは、Windows の［設定］→［アプリ］から行います。録音（`ドキュメント\Kakitome\Library`）は残ります。

## 動作環境

- Windows 11 24H2 以降
- メモリ 8 GB 以上（要約用 AI を使うなら 16 GB を推奨）
- GPU・NPU は不要です。

## 既知の制限

- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されます。
- ARM 版は、動作を確認できていません。
- NPU（AI 専用プロセッサー）には、まだ対応していません。
- 話者の区別（誰が話したか）には対応していません。
