# Kakitome 2.0.0-beta.8

## 変更点

- **話者が実際より大幅に多く分かれてしまう問題を修正しました。**
  - BGM や効果音のある動画などで、2 人の会話が「話者 95」のように細かく分かれていました。
  - 声の特徴を長めの音声から取り直し、録音全体に共通する成分（マイクや BGM）を取り除いてから、似た声をまとめるようにしました。手元の 57 分の動画では 95 人 → 2 人になりました。
  - 人数が分かっているときは、設定 ›［文字起こし・要約］›［話者の人数］で指定すると、その人数にまとめます。
- **要約が会議の型に無理に当てはめられる問題を修正しました。**
  - 録音の種類（会議・講義・会話や動画など）を先に判断し、合う項目だけを出すようにしました。会議でない録音に「決定事項」「アクションアイテム」が出なくなります。
  - 長い録音でも要点を 3 つ以上まとめるようにしました。
  - 担当者に「audio-50」のような内部の番号や「指定なし」が出ないようにしました。
- すでに処理済みの録音に反映するには、録音画面の［再文字起こし］（話者と要約）または［要約を作り直す］（要約のみ）を実行してください。

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。設定は残ります。

## 既知の制限

- テスト版（pre-release）です。
- 話者分離は、複数の人が同時に話している部分や、声の似た人どうしでは間違えることがあります。
- NPU（AI 専用プロセッサー）には、まだ対応していません。
- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されることがあります。
