# Kakitome / カキトメ 2.0.0-beta.7

## 変更点

- **アプリが途中で落ちる不具合を修正しました。**
  - 話者分離（beta.6 で追加）が始まるとアプリが終了していました。Windows に含まれる別バージョンの部品（ONNX Runtime）が読み込まれていたためです。Kakitome に同梱したものを使うようにしました。ReazonSpeech による文字起こしも同じ対策をしています。
  - Kakitome の外で削除した録音を開くと、アプリが終了していました。「この録音はライブラリにありません。」と表示するようにしました。
- beta.6 で途中のまま止まっていた話者分離は、アップデート後の起動時に自動で再開します。

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.0-beta.7_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.0-beta.7_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.0-beta.7_x64.msi`） |

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。設定は残ります。

## 既知の制限

- テスト版（pre-release）です。
- 話者分離は、複数の人が同時に話している部分や、声の似た人どうしでは間違えることがあります。
- NPU（AI 専用プロセッサー）には、まだ対応していません。
- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されることがあります。
