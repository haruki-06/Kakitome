# Kakitome 2.0.0-beta.3

## 変更点

- **設定のモデル画面を、用途ごとに分けました。**「音声認識」「要約用 AI（任意）」「ツール」の 3 つのまとまりで表示します。
- 各モデルに、どんな PC・用途に向いているかの短い説明を付けました。
  - Whisper large-v3-turbo：最も高精度。GPU のある PC におすすめ
  - Whisper small：GPU のない PC（CPU のみ）におすすめ
  - ReazonSpeech：日本語専用でとても軽い。静かな場所での録音向け
  - Qwen3 4B：要約の精度が最も高い。メモリ 16 GB 以上の PC 向け
  - Phi-4-mini：Qwen3 の代わりに使える要約モデル
  - NPU（AI 専用プロセッサー）を使うモデルには、まだ対応していません。
- **要約用 AI も自動でダウンロードするようにしました。** メモリ 16 GB クラス以上の PC で、要約用 AI が 1 つもないときに、推奨の Qwen3 4B（約 2.3 GB）をダウンロードします。
  - ［設定］→［文字起こし・要約］→［詳細設定］→［要約の方法］を「抜き出しのみ」にしている場合は、ダウンロードしません。
  - 自動ダウンロードは、これまでどおり［設定］→［モデル］でオフにできます。
- **修正**：アップデートのたびに、設定と処理の履歴が初期化されていた問題を修正しました（ライブラリとモデルは影響を受けていません）。
  - 2.0.0-beta.3 より前の版から上げるときは、古い版の仕組みにより、この 1 回だけ設定が初期化されます。それ以降のアップデートでは設定が残ります。
- **修正**：テスト版どうし（2.0.0-beta.N）のアップデートで、上書きされずに 2 つ登録されてしまう問題を修正しました。

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.0-beta.3_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.0-beta.3_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.0-beta.3_x64.msi`） |

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- 2.0.0-beta.1 / beta.2 からは、Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。

## 既知の制限
