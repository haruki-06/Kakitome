# Kakitome 2.0.0-beta.10

## 変更点

- **初回起動の直後に録音・取り込みしたものが、文字起こしされないまま止まる問題を修正しました。**
  音声認識モデルのダウンロードが終わる前に処理が始まると「失敗」になっていました。今後は、モデルの準備ができた時点で自動でやり直します。
- **キューや設定に出るエラーの説明を日本語で表示するようにしました。**（これまでは英語のままでした）
- **アップデートなどでアプリが閉じられるときに、まれにアプリが異常終了する問題を修正しました。**（クリップボードにコピーした後に起きることがありました）

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.0-beta.10_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.0-beta.10_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.0-beta.10_x64.msi`） |

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。設定は残ります。

## 既知の制限

- テスト版（pre-release）です。
- NPU（AI 専用プロセッサー）には、まだ対応していません。
- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されることがあります。
