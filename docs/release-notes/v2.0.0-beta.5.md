# Kakitome / カキトメ 2.0.0-beta.5

## 変更点

- **録音画面の文字起こしを、さらに読みやすくしました。**
  - 時刻（[00:08:36] のような表示）を消しました。
  - 話の切れ目で句点（。）を補い、3 文ほどごと・話題が変わるところ（「次に、」「最後に、」など）で改行します。
  - 再生中の部分のハイライトと、クリックした位置からの再生は、これまでどおり使えます。
- **要約も同じ見た目にしました。** 時刻の表示をなくし、見出しと「・」の箇条書きで表示します。録音の該当箇所がある項目は、クリックするとその位置から再生します。
- **再生バーの下に、現在の位置と全体の長さ（例：08:36 / 32:12）を表示するようにしました。**

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.0-beta.5_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.0-beta.5_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.0-beta.5_x64.msi`） |

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。設定は残ります。

## 既知の制限

- テスト版（pre-release）です。
- NPU（AI 専用プロセッサー）には、まだ対応していません。
- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されることがあります。
