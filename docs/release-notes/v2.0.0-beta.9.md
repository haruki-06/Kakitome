# Kakitome / カキトメ 2.0.0-beta.9

## 変更点

- **話者分離（誰が話したかの区別）の機能を削除しました。**
  - 実際の録音で十分な精度が出なかったためです。設定の「話者を区別する」「話者の人数」、モデル画面の「話者の識別」、録音画面の［話者名を変更］もなくなります。
  - beta.6〜8 で話者分離された録音は、録音画面の［再文字起こし］を実行すると元の表示に戻ります。
  - ダウンロード済みの話者分離モデル（約 34 MB）は使われなくなります。不要なら `%LOCALAPPDATA%\Kakitome\Models\speaker-diarization-v1` フォルダを削除してかまいません。
- beta.8 の要約の改善（録音の種類に合わせた項目、要点 3 つ以上）はそのまま残っています。

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.0-beta.9_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.0-beta.9_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.0-beta.9_x64.msi`） |

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。設定は残ります。

## 既知の制限

- テスト版（pre-release）です。
- NPU（AI 専用プロセッサー）には、まだ対応していません。
- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されることがあります。
