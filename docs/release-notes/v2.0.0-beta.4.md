# Kakitome 2.0.0-beta.4

## 変更点

- **GPU の見分け方を改善しました。** 実際に文字起こし・要約で使う仕組み（Vulkan）から、GPU の種類とメモリ容量を直接調べるようにしました。
  - 外付け GPU（メモリ 2 GB 以上）があれば、文字起こしにその GPU を使います。外付け GPU と内蔵 GPU の両方がある PC でも、必ず外付け GPU を選びます。
  - **内蔵 GPU しかない PC では、CPU で文字起こしするようにしました。** これまでは内蔵 GPU で動くことがあり、効果を確かめていない状態でした。
  - 以前に接続していた外付け GPU ボックスなど、今は使えない GPU を「あり」と判断することがなくなりました。
- **要約用 AI を、GPU のメモリが足りるときだけ GPU で動かすようにしました**（目安 6 GB 以上）。GPU で失敗した場合は、CPU でやり直します。これまでは、GPU のメモリが少ない PC で要約が簡易版（抜き出し）になることがありました。

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.0-beta.4_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.0-beta.4_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.0-beta.4_x64.msi`） |

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。設定は残ります。

## 既知の制限

- テスト版（pre-release）です。
- NPU（AI 専用プロセッサー）には、まだ対応していません。
- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されることがあります。
