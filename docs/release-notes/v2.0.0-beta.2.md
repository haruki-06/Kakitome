# Kakitome 2.0.0-beta.2

## 変更点

- **足りないモデルとツールを自動でダウンロードするようにしました。** 起動時に次のものがなければ、自動でダウンロードを始めます。
  - 音声認識モデルが 1 つもない場合：この PC に推奨のモデル（GPU のある PC は Whisper large-v3-turbo、ない PC は Whisper small）
  - URL 取り込み用の yt-dlp がない場合：yt-dlp
- ダウンロード中はホーム画面にモデル名を表示し、進行状況は処理キューで確認・キャンセルできます。完了すると通知でお知らせします。
- モバイル回線やテザリングなど、従量制の接続では自動ダウンロードしません。
- ［設定］→［モデル］の「足りないモデルとツールを自動でダウンロードする」で、オフにできます。
- 要約用の AI モデル（約 2.5 GB）は、これまでどおり必要な場合だけ手動で入れてください。

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.0-beta.2_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.0-beta.2_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.0-beta.2_x64.msi`） |

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- 2.0.0-beta.1 からは、Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。
