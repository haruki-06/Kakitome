# Kakitome / カキトメ 2.0.0-beta.11

## 変更点

- **新しいバージョンのお知らせ**
  - 新しいバージョンが公開されると、ホーム画面と Windows の通知でお知らせします。［ダウンロードページ］でリリースページを開きます。
  - 確認は 1 日 1 回、GitHub に最新のバージョンを問い合わせるだけです。録音などのデータは送りません。
  - ［設定］→［全般］でオフにでき、［今すぐ確認］もできます。
- **ログと「不具合の報告」**
  - 動作の記録（ログ）を `%LOCALAPPDATA%\Kakitome\Logs` に保存するようにしました（14 日分）。
  - ［設定］→［データとバックアップ］→［不具合の報告］の［診断情報を保存…］で、ログ・PC の情報・設定・処理の履歴を 1 つの zip にまとめて保存できます。GitHub の Issue に添付してください。
  - 録音・文字起こし・要約・タイトルは含まず、ユーザー名やフォルダー名は伏せます（ログにはプロジェクト名やファイル名が含まれることがあります）。

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.0-beta.11_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.0-beta.11_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.0-beta.11_x64.msi`） |

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。設定は残ります。

## 既知の制限

- テスト版（pre-release）です。
- NPU（AI 専用プロセッサー）には、まだ対応していません。
- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されることがあります。
