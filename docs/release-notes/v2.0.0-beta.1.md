# Kakitome 2.0.0-beta.1

SmartRec は **Kakitome（かきとめ）** に名前が変わりました。オープンソース（MIT ライセンス）として公開するための準備版です。
録音・文字起こし・要約・検索は、これまでどおりすべてこの PC の中で行います。

## 変更点

- アプリ名を SmartRec から Kakitome に変更しました。アプリ・インストーラー・スタートメニュー・保存先フォルダーの名前が変わります。
  - 設定・モデル：`%LOCALAPPDATA%\Kakitome`
  - ライブラリ：`ドキュメント\Kakitome\Library`
  - バックアップファイル：`.kakitome-backup`
- **SmartRec のデータは引き継ぎません。** Kakitome は SmartRec とは別のアプリとしてインストールされます。
  - 音声認識モデルは、Kakitome の［設定］→［モデル］から入れ直してください。
  - SmartRec の録音（`ドキュメント\SmartRec\Library`）は、そのまま残ります。
- MIT ライセンスで公開するためのファイル（ライセンス、セキュリティ報告の窓口、自動ビルド）を追加しました。

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.0-beta.1_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.0-beta.1_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.0-beta.1_x64.msi`） |

## インストール

1. PC に合った `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。管理者権限は不要です。
2. 起動後、［設定］→［モデル］で音声認識モデルをインストールします。
3. SmartRec が不要になったら、Windows の［設定］→［アプリ］→［インストールされているアプリ］から SmartRec をアンインストールしてください（両方を同時に起動すると、録音の開始/停止ショートカットが重なります）。

## 動作環境

- Windows 11 24H2 以降（x64。ARM64 版は動作未確認）
- メモリ 8 GB 以上（PC 内の AI で要約する場合は 16 GB を推奨）

## 既知の制限

- テスト版（pre-release）です。
- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されることがあります。
