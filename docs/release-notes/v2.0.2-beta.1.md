# Kakitome 2.0.2-beta.1

## 変更点

- **文字起こしで、一度出た言葉を最後まで繰り返してしまう問題を直しました。**
  - 動画などで、「黒玉:」のような言葉がほぼすべての行の頭に付き続けることがありました。直前に認識した文章をヒントとして音声認識に渡していたため、一度の間違いを真似し続けていたのが原因です。
  - 直前の文章をヒントに使うのをやめました。手元の動画（22 分）では「黒玉」が 323 回 → 2 回（実際に話された分だけ）になり、句点「。」も正しく入るようになりました。処理も速くなっています。
  - 音声認識が台本のように付けてしまう「名前:」も、何度も出てくる場合は取り除くようにしました（元の文章は記録に残ります）。
- すでに文字起こし済みの録音に反映するには、録音画面の［再文字起こし］を実行してください。

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.2-beta.1_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.2-beta.1_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.2-beta.1_x64.msi`） |

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。ライブラリ・設定・モデルはそのまま残ります。

## 既知の制限

- テスト版（pre-release）です。
- NPU（AI 専用プロセッサー）には、まだ対応していません。
- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されることがあります。
