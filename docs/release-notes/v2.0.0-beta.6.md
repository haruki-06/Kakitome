# Kakitome / カキトメ 2.0.0-beta.6

## 変更点

- **話者分離（誰が話したか）に対応しました。**
  - 文字起こしの後に声を聞き分けて、「話者 1」「話者 2」…のように区別します。録音画面の本文と、文字起こしファイル（Markdown / JSON）の両方に入ります。
  - 録音画面の［話者名を変更］で、「話者 1」を実際の名前に変えられます。
  - マイクとシステム音声を一緒に録音した場合は、それぞれの中で区別します（手元の人と相手側が混ざりません）。
  - 設定 ›［文字起こし・要約］で、オン/オフと話者の人数（自動 / 2〜6 人）を選べます。既定はオンです。
  - 必要なモデル（約 34 MB）は起動時に自動でダウンロードされます。CPU で動き、1 時間の録音で数分ほどかかります。
  - 既存の録音に使うときは、録音画面の［再文字起こし］を実行します。

## ダウンロードするファイル

| ファイル | 対象 |
|---|---|
| `Kakitome_2.0.0-beta.6_x64.msi` | 通常の Windows PC（Intel / AMD）。迷ったらこちら |
| `Kakitome_2.0.0-beta.6_arm64.msi` | ARM 版 Windows（Snapdragon など） |
| `SHA256SUMS.txt` | ダウンロードしたファイルの確認用（PowerShell で `Get-FileHash .\Kakitome_2.0.0-beta.6_x64.msi`） |

## インストール・アップデート

- 新しく入れる場合は `.msi` をダブルクリックします。「Windows によって PC が保護されました」と表示されたら、［詳細情報］→［実行］を選びます。
- Kakitome を終了してから `.msi` を実行すると上書きアップデートされます。設定は残ります。

## 既知の制限

- テスト版（pre-release）です。
- 話者分離は、複数の人が同時に話している部分や、声の似た人どうしでは間違えることがあります。
- NPU（AI 専用プロセッサー）には、まだ対応していません。
- インストーラーには有料の署名がないため、初回に SmartScreen の確認が表示されることがあります。
