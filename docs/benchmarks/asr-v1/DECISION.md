# ASR benchmark v1 — analysis and decision

Results: [README.md](README.md) (generated by `Kakitome.Bench report`), raw per-item data in `raw/`.

## What was measured

- Candidates: whisper.cpp (Whisper.net 1.9.1) with `large-v3-turbo q5_0` and `small q5_1`, each with the Vulkan GPU
  runtime ("auto") and CPU-only ("cpu"); sherpa-onnx 1.13.8 with ReazonSpeech k2 v2 int8 (CPU).
- Corpus v1: 26 Japanese items (lecture, meeting, interview, casual, numbers, proper nouns, technical terms,
  mixed ja/en, fillers, two ~78 s long items) + 2 English items, synthesized with Windows voices (Ayumi, Haruka,
  Ichiro; Zira for English) and mixed with pink-ish noise at 15 dB and 5 dB SNR. ≈ 19 min of audio per run.
- Path: the product path (WAV reader → 16 kHz resampler → VAD chunker → engine), language hint `ja`/`en`.

## Findings

| | ja CER clean / 5 dB | en WER | RTF GPU | RTF CPU | Peak RAM |
|---|---|---|---|---|---|
| Whisper large-v3-turbo q5_0 | 4.1 % / 5.0 % | 0 % | 0.039 | 1.64 | 0.75–1.2 GB |
| Whisper small q5_1 | 6.8 % / 8.7 % | 0 % | 0.029 | 0.36 | 0.6–0.7 GB |
| ReazonSpeech k2 v2 int8 | 7.6 % / 22.2 % | n/a (ja only) | – | 0.027 | 0.47 GB |

- large-v3-turbo is the most accurate in every category incl. mixed ja/en (10 %) and noise; on CPU it is slower
  than real time even on a fast desktop CPU, so it is not usable CPU-only on laptops.
- Whisper small is ~2.5 points worse but robust to noise and ~4.6× faster than large on CPU.
- ReazonSpeech is ~13× faster than Whisper small on CPU and good on clean speech, but degrades sharply with noise
  and is Japanese-only. It needs short utterances: given multi-sentence input it drops earlier speech, and
  input that starts mid-word is mis-decoded. The provider therefore decodes 2–6 s pause-delimited utterances with
  200 ms context and 300 ms silence padding (found and fixed during this benchmark).
- "numbers" CER is dominated by notation (Whisper writes digits, references use kanji numerals), not mishearing.

## Decision (hardware-aware Pareto)

| Hardware | Default model | Rationale |
|---|---|---|
| Discrete GPU (NVIDIA / AMD RX / Intel Arc) via Vulkan | whisper-large-v3-turbo-q5_0 | best accuracy, RTF 0.04 |
| CPU only / integrated graphics | whisper-small-q5_1 | accuracy + noise robustness at CPU-feasible cost |
| Japanese, fastest / lowest power (user choice) | reazonspeech-k2-v2-int8 | RTF 0.03 on CPU; clean audio only |

Implemented in `AsrDefaults.PreferenceFor` (user override in settings wins), `AsrDefaults.RecommendedModel` for
first-run/Model Manager, and `GpuAccelerationProbe`.

## Limitations / untested hardware matrix

- Measured on one **desktop** (Ryzen 7 9700X, RTX 5070 Ti, 61 GB RAM, AC). Not measured: x64 laptop without dGPU,
  laptop with dGPU, Copilot+/NPU laptop, ARM64 (docs/08 targets 1–4). Laptop CPUs are expected to be 2–3× slower
  than these CPU numbers; battery/thermal impact was not measured.
- Integrated GPUs are treated as "no capable GPU" (not measured); Vulkan on an iGPU may or may not beat the CPU.
- Synthetic TTS speech is cleaner than real recordings; absolute CER is optimistic. Use for ranking only.
- Not yet benchmarked: Windows AI speech recognition (no stable file-transcription API), Qwen3-ASR (available in
  sherpa-onnx 1.13.8; candidate for v2), speaker diarization.
