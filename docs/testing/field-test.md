# 実機テストのお願い（ノート PC）

Kakitome をほかの PC で試してもらうときの手順です。30〜60 分ほどかかります。結果は最後に保存する「診断情報」の zip と、下のチェック表でまとめて返してください。

## 準備

1. [Releases](https://github.com/haruki-06/Kakitome/releases) から、PC に合った `.msi` をダウンロードしてインストールします（Intel / AMD は `x64`、Snapdragon などは `arm64`）。
   「Windows によって PC が保護されました」と出たら［詳細情報］→［実行］。
2. ノート PC は、**電源につないだ状態**と**バッテリーだけの状態**の両方で試せると助かります。

## 試すこと

| # | やること | 確認すること | 結果（○ / × / メモ） |
|---|---|---|---|
| 1 | 初めて起動する | モデルのダウンロードが［キュー］に出て、終わる（数分〜十数分） | |
| 2 | ダウンロード中に 1 分ほど録音して停止 | ダウンロードが終わると、自動で文字起こしされる | |
| 3 | 5 分ほど会話や動画の音を録音（マイクと PC の音） | 停止後、文字起こしと要約ができる。録音中にプレビューが出る | |
| 4 | 録音中にマイクを抜き差し（USB / Bluetooth があれば） | 録音が止まらず、音声が残る | |
| 5 | 録音中に PC をスリープ → 復帰 | 録音が保存されている | |
| 6 | 音声・動画ファイルをドラッグ & ドロップで取り込む | 文字起こしされる | |
| 7 | YouTube などの URL を取り込む | 文字起こしされる | |
| 8 | 録音画面で文字起こし・要約を読む／再生する | 表示が読みやすい、クリックした位置から再生される | |
| 9 | 検索で、文字起こしの中の言葉を探す | 見つかる | |
| 10 | バッテリーだけで 3 を試す | 処理が遅くなっても、PC が重くなりすぎない | |

気になったこと（重い・分かりにくい・文字起こしの間違いが多い など）は、何でもメモしてください。

## 結果の返し方

1. ［設定］→［データとバックアップ］→［不具合の報告］→［診断情報を保存…］で zip を保存します。
2. zip と、上の表（メモ付き）を送ってください。

zip には録音・文字起こし・要約は入っていません。ログにはプロジェクト名やファイル名が入ることがあります。
